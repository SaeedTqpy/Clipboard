# Clipboard — مدیریت حرفه‌ای کلیپ‌بورد macOS

**بومی، محلی و با تمرکز بر حریم خصوصی**

Clipboard یک برنامهٔ Menu Bar است که دو رابط مستقل دارد: Shelf سریع و تمام‌عرض که از لبهٔ واقعی پایین نمایشگر بالا می‌آید و پنجرهٔ مدیریت قابل تغییر اندازه که با کلیک روی آیکون Menu Bar باز می‌شود. تاریخچهٔ متن، لینک، تصاویر و فایل‌های کپی‌شده را در هر دو رابط می‌توان جستجو و مدیریت کرد. با **SwiftUI + AppKit** ساخته شده و از **Liquid Glass در macOS 26** و Material سیستم در macOS 15 تا 25 استفاده می‌کند.

**[مشاهده سایت سه‌بعدی Clipboard](https://saeedtqpy.github.io/Clipboard/)** · [English README](README.md) · [دانلود](#دانلود-و-نصب) · [تصاویر برنامه](docs/SCREENSHOTS.md) · [گزارش خطا](https://github.com/SaeedTqpy/Clipboard/issues)

> **نسخهٔ پیش‌نمایش توسعه‌دهندگان — v0.2.0.** در ۱۳ نوامبر ۲۰۲۶، همهٔ **۶۶ تست خودکار** نسخهٔ جدید Shelf و تگ‌های رنگی موفق شدند و خروجی Universal برای Apple Silicon و Intel ساخته شد. تست مجوز Accessibility، Paste واقعی و چندمانیتوره روی مک کاربر همچنان باقی است. این نسخه هنوز تأییدیهٔ انتشار عمومی ندارد.

## پیش‌نیازها

- **macOS 15 یا جدیدتر**؛ Liquid Glass در **macOS 26 به بالا**.
- پردازندهٔ **Apple Silicon یا Intel**.
- نصب نسخهٔ آماده نیازی به **Xcode یا Apple Developer Account** ندارد.
- برای **Paste خودکار** مجوز **PostEvent** (ارسال رویداد کیبورد) لازم است؛ مجوز AX مربوط به APIهای Accessibility مستقل است و برای همین مسیر Paste شرط نیست.

## آموزش سریع

۱. برنامه را باز کنید و آیکون را در **Menu Bar** ببینید.

۲. با **⌘⇧V** (Command + Shift + V؛ روی کیبورد ویندوزی متصل به مک، معمولاً **Win + Shift + V**) فقط Shelf پایین صفحه را باز کنید. برای پنجره مدیریت روی آیکون Clipboard در Menu Bar کلیک کنید؛ منوی تنظیمات و خروج با راست‌کلیک باز می‌شود.

۳. Monitoring را فعال کرده و متنی آزمایشی در Notes کپی کنید.

۴. در **Quick Shelf** روی سربرگ، متن یا تصویر کارت کلیک کنید تا محتوا کپی شود، پنل بسته شود و در برنامه‌ای که پیش از بازکردن Shelf فعال بود Paste شود. دکمه **Copy** فقط کپی می‌کند و منوی **•••** مستقل از Paste عمل می‌کند.

۵. برای Paste مستقیم به برنامهٔ دیگر، دسترسی **Accessibility** را در تنظیمات macOS فعال کنید.

۶. از منوی کارت‌ها برای **Pin، Move to Collection، Add to Paste Stack، Paste as Plain Text** و حذف استفاده کنید. گزینهٔ **Colored Tags** برای ایجاد، اتصال یا حذف تگ رنگی است؛ با کلیک روی تگ‌های بالای Shelf می‌توان آیتم‌ها را فیلتر کرد و با راست‌کلیک تگ را ویرایش کرد.

| میانبر | عملکرد |
| --- | --- |
| **⌘⇧V** / **Win + Shift + V** | باز و بسته‌کردن Quick Shelf پایین صفحه |
| **⌘1 تا ⌘9** | Paste آیتم‌های اول قابل مشاهده، در صورت دریافت میانبر توسط پنل |
| **Esc** | بستن پنل |
| **↑ / ↓** | انتخاب آیتم قبلی / بعدی |
| **Return** | Paste آیتم انتخاب‌شده |
| **Option + Return** | Paste متن بدون فرمت |
| **⌘P** | Pin یا Unpin |
| **⌘Backspace** | درخواست حذف آیتم انتخاب‌شده |

میانبر قدیمی **Ctrl + Shift + V** یک‌بار به **Command + Shift + V** مهاجرت می‌کند؛ سایر میانبرهای سفارشی حفظ می‌شوند. اگر Win در مک به Command نگاشت نشده است، تنظیمات Modifier Keys را بررسی کنید. Paste خودکار به مجوز **PostEvent** نیاز دارد؛ بدون آن، کلیک کارت فقط کپی می‌کند و Shelf باز می‌ماند تا پیام خطا نمایش داده شود.

## امنیت و حریم خصوصی

- تاریخچه **فقط روی دستگاه** نگهداری می‌شود و برنامه سرویس Sync، Analytics یا ارسال خودکار محتوا به شبکه ندارد.
- متن‌ها، مسیر فایل‌ها، پیش‌نمایش‌ها، عناوین و خروجی OCR تصاویر با **AES-GCM** رمزگذاری می‌شوند؛ اما محتوای فعال در RAM و کلیپ‌بورد خود macOS الزاماً رمزگذاری‌شده نیست.
- تشخیص برنامه‌های مدیریت رمز عبور و داده‌های محرمانه **به‌صورت Best Effort** انجام می‌شود؛ ضبط ناخواستهٔ رازها همچنان ممکن است.
- پاک‌شدن تاریخچه به معنی حذف قطعی از Backup قدیمی، APFS Snapshot یا حافظهٔ SSD نیست.
- از دست‌رفتن کلید Keychain ممکن است بازیابی تاریخچهٔ محلی را غیرممکن کند. برای انتقال به مک دیگر، از **Backup رمزگذاری‌شده با رمز مستقل** استفاده کنید.
- Backup صرفاً **مسیر فایل‌های خارجی** را ذخیره می‌کند، نه دادهٔ داخل آن فایل‌ها.
- نسخهٔ فعلی هنوز Sandbox و امضای دیجیتال برای توزیع عمومی ندارد.

**هنگام کار با رمز عبور، کلید خصوصی، توکن و اطلاعات حساس، Monitoring را غیرفعال کنید.**

## توسعه

برای Build محلی، Xcode و XcodeGen لازم‌اند:

```bash
brew install xcodegen
xcodegen generate --spec project.yml
xcodebuild test -project Clipboard.xcodeproj -scheme Clipboard \
  -configuration Debug -destination 'platform=macOS' CODE_SIGNING_ALLOWED=NO
```

بدون Xcode محلی از GitHub Actions دستی استفاده کنید.

Clipboard یک پروژهٔ مستقل است و وابستگی رسمی به Apple ندارد.


### آیکون برنامه

لوگوی جدید با هویت شیشه‌ای آبی و بنفش برای Clipboard آماده شده است. تصویر اولیه به یک نسخهٔ بازطراحی‌شده با گرافیک Native تبدیل می‌شود و در Build مک، فایل `Clipboard.icns` همراه برنامه بسته‌بندی می‌شود. [مستندات ساخت آیکون](docs/APP_ICON.md).


### اگر با کلیک روی کارت Paste انجام نمی‌شود

برای Paste خودکار با شبیه‌سازی کلید `⌘V`، مجوز مستقل **PostEvent** لازم است؛ مثبت‌بودن Accessibility به‌تنهایی کافی نیست. نسخه جدید هنگام نبود مجوز، پس از کپی‌کردن **Shelf را باز نگه می‌دارد** و دلیل عدم Paste را نشان می‌دهد؛ درخواست مجوز macOS هم نمایش داده می‌شود. نسخه‌های قدیمی را کامل ببندید، فقط اپ جدید داخل Applications را اجرا کنید و مجوز Clipboard را در **System Settings → Privacy & Security → Accessibility** فعال کنید. سپس یک بار برنامه را ببندید و دوباره باز کنید. اگر برنامه مقصد فوکوس نگیرد، متن همچنان کپی شده و می‌توانید با ⌘V دستی Paste کنید.


### گزارش خطای Paste

ارسال `⌘V` اکنون از مسیر رویداد سراسری macOS و فقط پس از تأیید فعال‌بودن برنامه مقصد انجام می‌شود. برای بررسی خطا، یک بار روی کارت بزنید و اگر Paste نشد، Shelf را دوباره باز کنید یا از **Settings → Paste Diagnostics** گزارش مرحلهٔ آخر را ببینید. دکمه **Copy Paste Diagnostics** فقط نام برنامه مقصد، مرحله اجرا و وضعیت مجوزها را کپی می‌کند و متن کلیپ‌بورد را ذخیره یا ارسال نمی‌کند. کدهای `P1` و `P2` دریافت کلیک و کپی موفق را نشان می‌دهند؛ `E3` یعنی مجوز، `E5` یعنی فوکوس، و `P4` یعنی فرمان `⌘V` ارسال شده ولی درج واقعی متن هنوز قابل تأیید خودکار نیست.


## امضای برنامه و مجوز macOS

نسخه‌های قبلی GitHub کاملاً **بدون امضا** ساخته می‌شدند. به همین دلیل ممکن بود با وجود فعال‌بودن Accessibility، خودِ برنامه `AX=false EVENT=false` گزارش کند. نسخه جدید پس از ساخت با **Ad-hoc Code Signing** امضا می‌شود و CI اعتبار امضا و شناسه `dev.clipboard.app` را بررسی می‌کند. این امضا **Developer ID یا Notarization نیست** و با هر Build تغییر می‌کند؛ بنابراین مجوز نسخه قبلی ممکن است با نسخه جدید معتبر نباشد. پس از نصب نسخه جدید در `/Applications/Clipboard.app`، فقط مجوز مربوط به Clipboard را Reset و دوباره اعطا کنید. دستورها و مراحل دقیق در [راهنمای TCC](docs/TCC_SIGNING.md) آمده است. در حالت خاص `AX=true EVENT=false` فقط `PostEvent` را Reset کنید، نه `Accessibility`. در **Settings → Paste Diagnostics → Refresh TCC & Signing Status** می‌توانید امضای نسخه فعلی و نتیجه واقعی بررسی مجوزها را ببینید. بعد از تأیید مجوز، Paste باید روی مک آزمایش شود؛ Build موفق به‌تنهایی اثبات عملکرد آن نیست.


**آخرین Build امضاشده (۱۳ نوامبر ۲۰۲۶):** [GitHub Actions #43501819795](https://github.com/SaeedTqpy/Clipboard/actions/runs/43501819795)، تمام **۶۶ تست** موفق شدند. نسخه Universal در Artifact با نام `Clipboard-macOS-adhoc` است. صحت امضای Ad-hoc و Designated Requirement در CI بررسی شد؛ مجوز مؤثر روی مک و Paste واقعی همچنان باید روی دستگاه تست شوند.


### رفع دقیق خطای AX=true / EVENT=false

در macOS مجوز **PostEvent** (ارسال کلید) از **Accessibility** جداست. وقتی Diagnostics مقدار `AX=true EVENT=false` نشان می‌دهد، دیگر Accessibility را Reset نکنید. برنامه را **کاملاً Quit** کنید، سپس در Terminal بزنید:

```bash
tccutil reset PostEvent dev.clipboard.app
```

برنامه نصب‌شده در `/Applications/Clipboard.app` را دوباره باز کنید. در **Settings → Paste Diagnostics** دکمه **Request Event Posting Access** را بزنید، درخواست macOS را تأیید کنید، برنامه را کاملاً ببندید و مجدداً اجرا کنید. با **Refresh TCC & Signing Status** بررسی کنید که `Event Posting (PostEvent): true` باشد. مجوز AX دیگر شرط ارسال کلید در مسیر Paste نیست. این دستور فقط PostEvent برنامه Clipboard را Reset می‌کند؛ بدون `sudo` اجرا کنید و مجوزهای همه برنامه‌ها را پاک نکنید.


## بازطراحی حرفه‌ای Quick Shelf

در macOS 26 از **Liquid Glass واقعی سیستم** و در macOS 15 از متریال Native استفاده شده است. پنل به لبه پایین نمایشگر متصل می‌ماند و کنترل‌ها با فاصله امن از Dock نمایش داده می‌شوند؛ فضای مشکیِ جداکننده در طراحی حذف شده است. کارت‌های حالت **Comfortable** عرض ۳۲۲ و ارتفاع ۲۸۳ پوینت دارند و در حالت **Compact** برای نمایشگر کوچک‌تر به ۲۷۸×۲۴۳ پوینت تغییر می‌کنند. انتخاب تراکم در فیلترهای بالای Shelf است و ارتفاع پنل هم‌زمان تغییر می‌کند. پیش‌نمایش متن، تصویر، لینک و رنگ خواناتر شده و Hover و کنتراست نیز بهبود یافته‌اند. رفتار Paste با یک کلیک روی بدنهٔ کارت حفظ شده است؛ Copy و منوی عملیات جدا هستند.
