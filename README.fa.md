# Clipboard — مدیریت حرفه‌ای کلیپ‌بورد macOS

**بومی، محلی و با تمرکز بر حریم خصوصی**

Clipboard یک برنامهٔ Menu Bar است که دو رابط مستقل دارد: Shelf سریع و تمام‌عرض که از لبهٔ واقعی پایین نمایشگر بالا می‌آید و پنجرهٔ مدیریت قابل تغییر اندازه که با کلیک روی آیکون Menu Bar باز می‌شود. تاریخچهٔ متن، لینک، تصاویر و فایل‌های کپی‌شده را در هر دو رابط می‌توان جستجو و مدیریت کرد. با **SwiftUI + AppKit** ساخته شده و از **Liquid Glass در macOS 26** و Material سیستم در macOS 15 تا 25 استفاده می‌کند.

**[مشاهده سایت سه‌بعدی Clipboard](https://saeedtqpy.github.io/Clipboard/)** · [English README](README.md) · [دانلود](#دانلود-و-نصب) · [تصاویر برنامه](docs/SCREENSHOTS.md) · [گزارش خطا](https://github.com/SaeedTqpy/Clipboard/issues)

> **نسخهٔ پیش‌نمایش توسعه‌دهندگان — v0.2.0.** در ۱۳ نوامبر ۲۰۲۶، همهٔ **۵۱ تست خودکار** نسخهٔ جدید Shelf و تگ‌های رنگی موفق شدند و خروجی Universal برای Apple Silicon و Intel ساخته شد. تست مجوز Accessibility، Paste واقعی و چندمانیتوره روی مک کاربر همچنان باقی است. این نسخه هنوز تأییدیهٔ انتشار عمومی ندارد.

## پیش‌نیازها

- **macOS 15 یا جدیدتر**؛ Liquid Glass در **macOS 26 به بالا**.
- پردازندهٔ **Apple Silicon یا Intel**.
- نصب نسخهٔ آماده نیازی به **Xcode یا Apple Developer Account** ندارد.
- برای **Paste خودکار** مجوز **Accessibility** لازم است؛ مشاهده و Copy معمولی بدون آن کار می‌کند.

## دانلود و نصب

نسخهٔ تأییدشده در [GitHub Actions Run #43424718936](https://github.com/SaeedTqpy/Clipboard/actions/runs/43428606866) قرار دارد.

۱. در قسمت **Artifacts** فایل **Clipboard-macOS-unsigned** را دانلود کنید. برای دسترسی ممکن است ورود به GitHub لازم باشد. فایل‌ها فعلاً بعد از **۱۴ روز** منقضی می‌شوند.

۲. ZIP بیرونی و سپس `Clipboard-macOS-unsigned.zip` داخلی را باز کنید.

۳. قبل از نصب، همهٔ نسخه‌های قدیمی Clipboard را از Menu Bar یا Activity Monitor ببندید. `Clipboard.app` جدید را جایگزین نسخهٔ قبلی در **Applications** کنید و فقط همین یک نسخه را اجرا کنید.

۴. برنامه فعلاً **امضا و Notarize نشده** است؛ اگر macOS مانع اجرا شد، تنها در صورت اعتماد به خروجی، مسیر **System Settings → Privacy & Security → Open Anyway** را بررسی کنید.

۵. تست اولیه را با داده‌های ساختگی مثل `Clipboard test 001` انجام دهید. برنامه در نصب تازه **با Monitoring خاموش** شروع می‌شود.

برای ساخت خروجی جدید، از [Workflow دستی](https://github.com/SaeedTqpy/Clipboard/actions/workflows/macos.yml) گزینهٔ **Run workflow** را بزنید. اجرای خودکار روی Push غیرفعال است.

## آموزش سریع

۱. برنامه را باز کنید و آیکون را در **Menu Bar** ببینید.

۲. با **⌘⇧V** (Command + Shift + V؛ روی کیبورد ویندوزی متصل به مک، معمولاً **Win + Shift + V**) فقط Shelf پایین صفحه را باز کنید. برای پنجره مدیریت روی آیکون Clipboard در Menu Bar کلیک کنید؛ منوی تنظیمات و خروج با راست‌کلیک باز می‌شود.

۳. Monitoring را فعال کرده و متنی آزمایشی در Notes کپی کنید.

۴. در **Quick Shelf** روی سربرگ، متن یا تصویر کارت کلیک کنید تا محتوا کپی شود، پنل بسته شود و در برنامه‌ای که پیش از بازکردن Shelf فعال بود Paste شود. دکمه **Copy** فقط کپی می‌کند و منوی **•••** مستقل از Paste عمل می‌کند.

۵. برای Paste مستقیم به برنامهٔ دیگر، دسترسی **Accessibility** را در تنظیمات macOS فعال کنید.

۶. از منوی کارت‌ها برای **Pin، Move to Collection، Add to Paste Stack، Paste as Plain Text** و حذف استفاده کنید. گزینهٔ **Colored Tags** برای ایجاد، اتصال یا حذف تگ رنگی است؛ با کلیک روی تگ‌های بالای Shelf می‌توان آیتم‌ها را فیلتر کرد و با راست‌کلیک تگ را ویرایش کرد.

| میانبر | عملکرد |
| --- | --- |
| **⌘⇧V** / **Win + Shift + V** | باز و بسته‌کردن Quick Shelf پایین صفحه |
| **⌘1 تا ⌘9** | Paste آیتم‌های اول قابل مشاهده، در صورت دریافت میانبر توسط پنل |
| **Esc** | بستن پنل |
| **↑ / ↓** | انتخاب آیتم قبلی / بعدی |
| **Return** | Paste آیتم انتخاب‌شده |
| **Option + Return** | Paste متن بدون فرمت |
| **⌘P** | Pin یا Unpin |
| **⌘Backspace** | درخواست حذف آیتم انتخاب‌شده |

میانبر قدیمی **Ctrl + Shift + V** یک‌بار به **Command + Shift + V** مهاجرت می‌کند؛ سایر میانبرهای سفارشی حفظ می‌شوند. اگر Win در مک به Command نگاشت نشده است، تنظیمات Modifier Keys را بررسی کنید. Paste خودکار به مجوز **Accessibility** نیاز دارد؛ بدون آن، کلیک کارت فقط کپی می‌کند و Shelf بسته می‌شود.

## امنیت و حریم خصوصی

- تاریخچه **فقط روی دستگاه** نگهداری می‌شود و برنامه سرویس Sync، Analytics یا ارسال خودکار محتوا به شبکه ندارد.
- متن‌ها، مسیر فایل‌ها، پیش‌نمایش‌ها، عناوین و خروجی OCR تصاویر با **AES-GCM** رمزگذاری می‌شوند؛ اما محتوای فعال در RAM و کلیپ‌بورد خود macOS الزاماً رمزگذاری‌شده نیست.
- تشخیص برنامه‌های مدیریت رمز عبور و داده‌های محرمانه **به‌صورت Best Effort** انجام می‌شود؛ ضبط ناخواستهٔ رازها همچنان ممکن است.
- پاک‌شدن تاریخچه به معنی حذف قطعی از Backup قدیمی، APFS Snapshot یا حافظهٔ SSD نیست.
- از دست‌رفتن کلید Keychain ممکن است بازیابی تاریخچهٔ محلی را غیرممکن کند. برای انتقال به مک دیگر، از **Backup رمزگذاری‌شده با رمز مستقل** استفاده کنید.
- Backup صرفاً **مسیر فایل‌های خارجی** را ذخیره می‌کند، نه دادهٔ داخل آن فایل‌ها.
- نسخهٔ فعلی هنوز Sandbox و امضای دیجیتال برای توزیع عمومی ندارد.

**هنگام کار با رمز عبور، کلید خصوصی، توکن و اطلاعات حساس، Monitoring را غیرفعال کنید.**

## توسعه

برای Build محلی، Xcode و XcodeGen لازم‌اند:

```bash
brew install xcodegen
xcodegen generate --spec project.yml
xcodebuild test -project Clipboard.xcodeproj -scheme Clipboard \
  -configuration Debug -destination 'platform=macOS' CODE_SIGNING_ALLOWED=NO
```

بدون Xcode محلی از GitHub Actions دستی استفاده کنید.
